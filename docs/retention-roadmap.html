Networth · Build Plan v1 · 2026-07-21

The road to 45% D30 — nine features, in order.

Everything below is scoped for the current stack (Angular PWA + FastAPI on Railway + Supabase + Kite). Build strictly in this order — items 1–2 are the spine; nothing later works without them. Target segment: active traders & complex-finance households.

01 Live-Data Spine (auto-sync everything) structural · 14%

Goal: the app is never stale — opening it always shows fresh numbers with zero manual steps.

  1. Kill the manual Kite-token load: backend job refreshes each account's session at market open; if re-login is truly needed, send a one-tap re-login link (bell already tracks this).
  2. Nightly cron: refresh prices, dividends, F&O positions, bond coupons → write a daily net-worth snapshot per person to Supabase (this table powers everything below).
  3. Service-worker cache of the last snapshot so the PWA opens instantly with data, then live-updates.
  4. Show a subtle "as of 9:42 am" freshness stamp on the dashboard — trust marker.

02 Daily Net-Worth Pulse on WhatsApp trigger · 25%

Goal: the reason to open arrives before they decide to open. Biggest single lever.

  1. Meta WhatsApp Cloud API direct (no BSP — ~₹40/mo at 10 users). Register template as utility category: "Net worth {{amt}} today ({{delta}}). Stocks {{s}}, F&O {{f}}, gold {{g}}. Tap: {{link}}".
  2. Backend cron 8:30 am IST reads yesterday-vs-today snapshots (from #01) → sends per user, deep-links into the dashboard.
  3. Web-push as free secondary channel for intraday events (dividend landed, F&O leg crossed break-even); iOS coach screen for Add-to-Home-Screen.
  4. Rule: if data is stale, don't send — a wrong Pulse is worse than none.

03 "Today" Feed home screen delight · 8%

Goal: the dashboard is never the same twice — every open pays off.

  1. New top-of-dashboard card stack, ranked by "charge": dividend landed > milestone near > F&O event > on-this-day-last-year > tax deadline > streak.
  2. Each card = one fact + one number + one tap-through. Max 3 cards; rotate daily.
  3. "While you were away" variant when last visit > 3 days: summarise everything that happened since.
  4. Celebrate arrivals (confetti on dividend/coupon credit) — money landing is the emotional peak.

04 Money-on-the-Table deadline engine structural · 9%

Goal: dated, rupee-quantified savings with countdowns — loss aversion + a clock.

  1. Chanakya's levers become persistent dashboard chips: "Harvest ₹1.25L LTCG → save ₹15,625 · 68 days left", advance-tax installments, 54EC windows, F&O expiry actions.
  2. Each chip: amount saved, deadline, one "show me how" tap into the relevant tax bot.
  3. Weekly WhatsApp digest of open chips ("₹41,200 still on the table").
  4. Mark-done state; celebrate captured savings ("you kept ₹15,625 this year").

05 Financial Health Score (0–100) delight · 4%

Goal: one personal number they chase — credit-score psychology.

  1. Score = weighted: diversification 25, tax-efficiency 25 (from open chips), emergency-fund months 20, concentration 15, income-stability 15. Computed nightly per family + per person.
  2. Dashboard ring with daily delta ("71 · +2 this week"); each sub-factor is a tappable fix that names the exact asset.
  3. Score change feeds the Today feed and the Pulse ("Health 71→73 after your bond buy").

06 Goal & FIRE countdown delight · 3%

Goal: every gain reframed as progress toward their date.

  1. Goals table (name, target ₹, target date). FIRE = expenses-based auto-goal (25× annual spend from the expenses tab).
  2. Daily recompute of projected finish date from real CAGR; surface ETA movement ("pulled 3 weeks closer") — the delta is the hook, not the bar.
  3. Milestone confetti at 25/50/75/100% and round numbers (₹1 Cr).

07 Setup Journey (honest progression) delight · 5%

Goal: progression that deepens investment — never gates their own data.

  1. Dashboard progress ring: Connect Kite → unlocks live P&L · Add a goal → unlocks FIRE · Log a month of expenses → unlocks tax optimizer · Set pledged capital → unlocks CAGR. Each unlock is real capability, not artificial scarcity.
  2. Streak counter on data-freshness actions (visited, logged, confirmed) — streaks never punish, only reward.
  3. Levels/badges as a status layer only (Level 6 Investor); zero utility locked behind them.

08 Family & advisor seats structural · 12%

Goal: other people depend on the data → nobody can leave.

  1. Per-person login with role scoping (you already model Ranjeev/Sanjeev/Maha) — each member sees their slice + the family view.
  2. Read-only CA/advisor seat with the tax pack (capital gains, TDS, chips from #04) exportable — the CA starts asking clients to keep it updated.
  3. Monthly family recap on WhatsApp ("family net worth +₹3.1L in June; Maha grew fastest").

09 Act-in-app surface structural · 20%

Goal: track → transact. The advice becomes a button. Hardest, highest ceiling — last on purpose.

  1. Phase 1 (no broker execution): every recommendation becomes a prepared order ticket — exact instrument, qty, price — one tap opens Kite with the order pre-staged via Kite Connect basket/publisher links.
  2. Phase 2: post-action reconciliation — the app detects the executed trade in the next sync and closes the loop ("harvest done, ₹15,625 kept").
  3. Phase 3 (later, regulated): direct order placement via Kite Connect order API for the accounts you already hold keys for.

Two rules that protect all of it: ① Never send a Pulse on stale data — silence beats a wrong number. ② Never lock a user's own money-view behind progression — gate depth, not data. Break either and the curve reverts to the 9% baseline faster than it climbed.
